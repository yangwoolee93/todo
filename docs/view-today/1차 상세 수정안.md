# View Today — 1차 상세 수정안

> **대상:** `TodayView` / `TodoList` (오늘 탭 일별 투두 리스트)  
> **목표:** 행 UI 정리, 상태 3종(미완료·완료·실패), ⋮ 메뉴, 복제

---

## 1. 행 레이아웃

```
[ ↑↓ ]  [ 상태 아이콘 ]  [ 투두 텍스트 …………………… ]  [ ⋮ ]
```

| 영역 | 동작 |
|------|------|
| ↑↓ | 순서 변경만 |
| 상태 아이콘 | 미완료 ↔ 완료 토글 (실패 상태에서는 변경 없음) |
| 투두 텍스트 | 상태 아이콘과 **동일** (클릭 시에만) |
| ⋮ 더보기 | 드롭다운 메뉴 — 상태 변경 **없음** |
| 행 빈 곳 | 클릭해도 상태 변경 없음 |

- `<label>` + `<input type="checkbox">` **제거**
- 아이콘·텍스트는 각각 `button`으로 분리

---

## 2. 상태 3종 (B안)

| 상태 | 값 | 아이콘 | 텍스트 스타일 |
|------|-----|--------|----------------|
| **미완료** | `pending` | 빈 네모 □ (둥근 모서리) | 기본 |
| **완료** | `completed` | 채운 네모 + ✓ | 취소선 + 흐림 + success 색 |
| **실패** | `failed` | 네모 테두리 + ✕ | 취소선 + failed 색 + 왼쪽 강조선 |

### 상태 변경 규칙

| 조작 | 동작 |
|------|------|
| **아이콘·텍스트 클릭** | `pending` ↔ `completed` 만 |
| **⋮ → 실패로 표시** | → `failed` |
| **⋮ → 다시 시도** | `failed` → `pending` |

실패는 ⋮ 메뉴에서만 지정 (실수 방지).

---

## 3. ⋮ 드롭다운 메뉴

| 항목 | 동작 |
|------|------|
| **수정** | `EditTodoModal` (묶음이면 일괄 수정) |
| **복제** | `AddTodoModal` 열기, **내용만 미리 채움**, 날짜·탭은 사용자 선택 |
| **실패로 표시** | `pending` / `completed` 일 때만 표시 |
| **다시 시도** | `failed` 일 때만 표시 → `pending` |
| **삭제** | 단독 confirm / 묶음 `DeleteBatchModal` |

---

## 4. 복제 UX

- ⋮ → **복제** 클릭
- `AddTodoModal` 오픈
- **내용:** 복제 대상과 동일
- **기본 탭:** 하루
- **기본 날짜:** 현재 `activeDate`
- 새 `batch_id` 없음 (1건 추가와 동일)

---

## 5. 데이터 모델

`is_completed: boolean` → **`status: 'pending' | 'completed' | 'failed'`**

```typescript
interface TodoItem {
  id: number
  content: string
  target_date: string
  status: TodoStatus
  created_at: number
  sort_order: number
  batch_id: string | null
}
```

- 구 JSON `is_completed: true` → `status: 'completed'` 로 마이그레이션
- IPC: `setTodoStatus({ id, status })`
