윈도우에서 일렉트론이 postinstall되지 않는 문제

- 권한인지 아닌지 모르겠지만 install.js가 설치를 정상적으로 진행하지 못함
- zip파일은 존재하나 이걸 풀어서 연결하는 과정이 스킵된 것으로 추정

해결법

- 수동으로 zip을 풀고 path.txt에 연결

경로 조회

```
Get-ChildItem "$env:LOCALAPPDATA\electron\Cache" -Recurse -Filter "electron-v34.5.8-win32-x64.zip" | Select-Object FullName, Length

// 경로
C:\Users\PRIVATEUSER\AppData\Local\electron\Cache\740ed593ce358efdc5b69876caba8b4754a393acf8df5369ae089b947a312aca\electron-v34.5.8-win32-x64.zip 116216928
```

해당 경로를 zip파일로 지정

```
$zip = "$env:LOCALAPPDATA\electron\Cache\740ed593ce358efdc5b69876caba8b4754a393acf8df5369ae089b947a312aca\electron-v34.5.8-win32-x64.zip"
Test-Path $zip
```

dist 파일 경로 지정

```
$dist = "node_modules\electron\dist"
if (Test-Path $dist) { Remove-Item $dist -Recurse -Force }
New-Item -ItemType Directory -Path $dist -Force | Out-Null
```

파일 압축 해제

```
Expand-Archive -Path $zip -DestinationPath $dist -Force
```

path.txt 생성(연결)

```
Set-Content -Path "node_modules\electron\path.txt" -Value "electron.exe" -NoNewline
```

설치 확인

```
Test-Path node_modules\electron\dist\electron.exe
Test-Path node_modules\electron\path.txt
Get-Content node_modules\electron\path.txt
Get-Content node_modules\electron\dist\version
```

zip 경로가 일치하게 세팅된 electron-manual-setting.ps1파일을 실행해도 될 것으로 예상됨

- 안되면 위 내용 수동으로 실행(윈도우에서만 이럴 것으로 일단 예상 추후 맥에서 실행 테스트 예정)
