## 3. 추가 상세·UI 정리 (당일 후반)

### 3-1. 스크롤바 스타일

- 전역 `*` / `html` 규칙 제거 → **`.scrollbar`** 클래스 + `index.css` 한 블록
- 변수: `--scrollbar-size`, `--scrollbar-inset`, `--scrollbar-gap`, thumb 색 (`:root` / `.dark`)
- Electron(Chromium) webkit 전용 — Firefox `scrollbar-color` 제거
- 가로 영역(MonthBoard, CalendarBar): `.scrollbar` + `.scroll-x-drag`

### 3-2. 오늘 탭 레이아웃

- **상단 고정** — 날짜 카드 + 전날/다른날짜/다음날 + 「+ 할 일 추가」
- **하단 full-width 추가 버튼 제거**
- **투두 목록만 스크롤** — `AppShell` `h-screen`, `html/body` `overflow-hidden`, `flex-1 min-h-0`
- FAB·하단 고정 바 대신 **헤더 우측 primary 버튼** 채택

### 3-3. 스크롤바 우측 여백 (1 + 2 + 1)

좌 `p-4`(16px)와 동일하게, 우측 콘텐츠↔카드 테두리 **총 16px** 유지.

| 구간 | 크기 | 적용 |
|------|------|------|
| 콘텐츠 ↔ bar | 4px | `.scrollbar-y-inset` → `padding-right: var(--scrollbar-gap)` |
| bar | 8px | `--scrollbar-size` |
| bar ↔ 카드 테두리 | 4px | 목록 카드 `pr-[var(--scrollbar-gap)]` |

- `margin-right` 음수 트릭 → Chromium에서 미적용, **폐기**
- `overflow-y: scroll` → bar 슬롯 항상 확보 (스크롤 유무 레이아웃 동일)

### 3-4. 윈도우 크기

`src/main/index.ts`:

- 초기 `720 × 720`
- 최소 `minWidth 720`, `minHeight 560`
