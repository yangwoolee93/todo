# Orbit Todo v0.2 로드맵 (임시)

> v0.2 마무리 방향을 정리한 **임시** 문서.  
> 0.2가 확정되면 이 내용을 바탕으로 다른 문서를 재작성할 예정.

---

## 작업 순서

| # | 항목 |
|---|------|
| 1 | 아이콘 변경 및 이름 재변경 |
| 2 | Windows 한정 트레이 |
| 3 | 데이터 저장 방식 재설계 토론 (JSON 유지 혹은 DB·테이블로 변경 고려) |
| 4 | 변경된 데이터로 Google Drive를 이용한 백업 및 동기화 테스트 |
| 5 | 기기별 설계 고안 — 앱 정보로 기기를 구별해 백업에 따로 저장하고, 복원할 때 비교·복원·합본 저장 |
| 6 | 테스트 Google Drive 처리 |

---

## 4 · 5 · 6 관계

- **4**가 되면 **5**도 같은 흐름에서 적용해 본다.
- **6**은 **4와 5**를 테스트 Google Drive 환경에서 검증한다.
