# Orbit

할 일과 메모를 이 기기에 두는 데스크톱 앱입니다. Windows와 macOS에서 쓸 수 있고, 별도의 서버는 없습니다. Google 계정으로 로그인하면 그 계정의 Drive로 동기화할 수 있습니다.

- 홈: https://yangwoolee93.github.io/todo/
- 개인정보 처리방침: https://yangwoolee93.github.io/todo/privacy.html

## 설치

현재 받을 수 있는 빌드는 **0.1.0**입니다. Electron으로 만든 버전입니다.

- 릴리즈: https://github.com/yangwoolee93/todo/releases/tag/v0.1.0

개발 중인 **0.2.0**은 Tauri로 옮긴 버전입니다. Google Drive 동기화를 포함한 뒤, Google API를 게시한 다음 릴리즈할 예정입니다. 0.2.0 설치 파일은 아직 없습니다.
