# [최종 기능 정의서] 단기 프로젝트: 가로 스크롤형 투두 캘린더 (Win)

## 1. 개요 (Overview)

- **제품명**: 가로 스크롤형 데스크톱 투두 애플리케이션
- **플랫폼**: Windows Desktop Application (Electron + React)
- **목적**: 격자형 달력의 복잡함을 배제하고, 가로 드래그 중심의 일별 타임라인을 통해 투두를 관리하는 초경량 스케줄러.
- **범위 제약 (Out of Scope)**: 본 앱은 연(Year) 단위 조회 등 월 이상의 광범위한 조회 기능은 **일절 제공하지 않는다.** 오직 선택된 **'특정 월(Month)'** 내의 일자별 데이터 흐름만 관리한다.

## 2. 데이터 모델 (Data Model Specification)

개발 효율성과 로직 재활용을 위해 단일 엔터티 구조를 지향하며, '통합(전체) 여부'를 구분하는 인자를 둡니다.

TypeScript

```
interface TodoItem {
  id: number;           // Date.now() 또는 DB Auto-Increment 값
  content: string;      // 1줄 이내 제한 텍스트
  is_global: boolean;   // true: 전체(통합) 투두 / false: 일별 예외 및 일별 독립 투두
  target_date: string;  // "YYYY-MM-DD" (is_global이 false일 때만 유효)
  is_completed: boolean;// 완료 여부 (체크 상태)
  is_deleted: boolean;  // 통합 투두가 특정 날짜에서 삭제(제외)되었음을 마킹하기 위함
}
```

### 💡 로직 재활용 규칙 (질문자님 제안 반영)

- **조회(Read)**:
  - 5월 24일 조회 시 ➡️ is_global: true인 항목들과 target_date: "2026-05-24"인 항목들을 한 번에 쿼리(또는 필터링)하여 화면에 합쳐서 뿌린다.
- **생성(Create)**:
  - 일반 일별 생성 ➡️ is_global: false, target_date에 활성 날짜 삽입.
  - 통합 투두 생성 ➡️ UX적으로 같은 입력창을 쓰되 인자값만 is_global: true로 전달하여 저장.
- **삭제/체크(Update/Delete 예외)**:
  - is_global: true인 통합 투두를 특정 날짜에서 체크하거나 삭제하면, 원본을 건드리지 않고 해당 날짜용 복사본(is_global: false, target_date: "해당날짜")을 생성하여 상태(is_completed 또는 is_deleted)를 기록한다.

## 3. 기능 요구사항 (Functional Requirements)

### F-01: 가로 드래그 캘린더 바 (상단)

- 사용자가 선택한 특정 월(Month)의 일자들이 가로 횡형으로 나열된다.
- 상/하 스크롤 없이 단일 행 전체가 '1일'을 의미한다.
- 마우스 좌/우 드래그를 통해 날짜 라인을 스크롤할 수 있다.
- 특정 일자를 클릭하면 해당 날짜가 '활성 날짜(Active Date)'로 지정된다.

### F-02: 일별 투두 리스트 (중앙)

- **생성 및 체크 제한**: 투두의 신규 생성 및 완료 체크 액션은 **오직 이 일별 뷰에서만 가능**하다.
- **1줄 제한**: 입력창 및 데이터 저장 시 개행을 허용하지 않으며, 한 줄 이내로 입력을 제한한다.
- **로직 일원화**: 통합 투두와 일반 투두는 동일한 생성/삭제/조회 로직을 공유하되, 내부 인자값으로 마킹을 분기한다.

### F-03: 월별 모아보기 테이블 (하단)

- **특정 월 제한**: 선택된 '특정 월'의 1일부터 말일까지의 데이터만 취합한다. (연 단위 이상 확장 불가)
- **레이아웃**: 1일부터 31일까지 세로 행으로 순차 정렬된 표(Table) 형태를 가진다.
- **제약 조건**: 본 뷰는 오직 **조회(Read-Only)** 전용이며, 항목을 클릭해도 수정/체크 등의 인터랙션이 발생하지 않는다.

### F-04: 로컬 데이터 백업 및 외부 출력

- 사용자가 지정한 경로에 현재 저장된 데이터 스펙을 SQL 스크립트(.sql 파일) 또는 이관 가능한 데이터 폼 파일로 안전하게 익스포트한다.
