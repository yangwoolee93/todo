## 🎉 Simple Todo v0.1.0 - Prototype Release

### 개요

가로 스크롤 중심의 **초경량 투두 캘린더 데스크톱 앱**.  
복잡한 달력 대신 **일별 타임라인 드래그**로 직관적인 일정 관리를 제공합니다.

---

### ✨ 주요 기능

#### ✅ 일별 투두 리스트

- 선택된 날짜의 투두 한눈에 관리
- 투두 추가/삭제/완료 체크
- 1줄 제한으로 간결함 유지

#### 📊 월별 모아보기

- 선택 월 전체 투두 한눈에 조회 (Read-Only)
- 날짜별 요약 테이블
- 월 범위 내 데이터만 제공

#### 💾 데이터 백업

- 로컬 저장소 자동 저장
- SQL 스크립트 형식 내보내기 지원
- JSON 형식 내보내기, 불러오기 지원
