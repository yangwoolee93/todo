- 일시: 2026-11-19
- 대상: `apps/mac`
- 상태: 메뉴를 `orbit.json`의 `menu` 키에 저장.

## 구조

- 프로젝트가 데이터를 가진다. 페이지는 그 아래 보기.
- 종류는 타임라인, 메모. 나중에 늘 수 있다. 만든 뒤 종류는 바꾸지 않는다.
- 같은 프로젝트에 같은 종류 페이지를 여러 개 둘 수 있다. 구분은 이름.
- 페이지에서 생길 데이터는 프로젝트에 둔다. 이번 단계에는 항목 데이터가 없다.
- 필터는 종류마다 나중에 정한다. 지금은 없다.

## 화면

- 프로젝트 추가: 사이드바 상단에서 이름만. 프로젝트 화면이 열린다.
- 페이지 추가: 프로젝트 화면 헤더에서 종류를 고른 뒤 이름. 입력은 종류마다 따로 둔다. 추가 후에도 프로젝트 화면에 남고 카드가 생긴다.
- 프로젝트 이름: 프로젝트 화면. 하위 페이지를 카드로 보여 준다.
- 접기·펼치기: 이름 오른쪽 화살표. 하위 항목이 선택된 채 접으면 화면은 그대로 두고, 선택 표시만 프로젝트로 옮긴다. 다시 펼치면 선택 표시는 그 페이지로 돌아온다.
- 페이지를 열면 이름과 종류. 메뉴에서는 그 줄이 선택되고 목록이 펼쳐진다.
- 종류 아이콘은 메뉴 항목, 페이지 제목, 프로젝트 카드 제목 앞에 둔다.
- 헤더의 더보기에서 이름 수정과 삭제. 프로젝트 화면에는 페이지 추가도 있다. 추가, 더보기, 이름 수정은 바깥을 누르면 닫힌다.
- 선택한 것이 없으면 오른쪽은 비어 있다.
- 삭제 확인: 내용이 있는데 삭제하시겠습니까?
- 페이지 삭제: 그 페이지만. 프로젝트 삭제: 하위 페이지도.

## 저장

- 파일은 `orbit.json`. `menu`에 프로젝트, 페이지, 마지막 선택, 수정 시각.
- 다른 최상위 키는 메뉴를 저장할 때 유지한다.
- 다시 열면 마지막 화면을 연다.
- 삭제는 파일에서 항목을 뺀다. 동기화용 삭제 표시는 나중에.
